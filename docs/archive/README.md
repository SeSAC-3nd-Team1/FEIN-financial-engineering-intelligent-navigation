# Archived documentation

이 디렉터리는 완료된 migration/retirement 당시의 상태를 증거로 보존한다.

Archive 문서는 **현재 운영 구조의 source of truth가 아니다.** 현재 구조는 상위 `docs/` 문서와 `data/docs/`, 실제 코드/Alembic head를 기준으로 확인한다.

현재 보존 문서:

- `DATABASE_SPECIFICATION_20260815.md`: 금융/API PostgreSQL Raw가 retire되기 전 Azure PostgreSQL snapshot
- `RAW_BLOB_MIGRATION_REPORT.md`: SQL Raw → Azure Blob migration 당시 검증 결과

과거 수치와 경로는 당시 작업 재현/감사용으로만 해석한다.
